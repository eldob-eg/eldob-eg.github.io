# موقع El-Dob ✂️

موقع المحل ومعاه لوحة تحكم بباسورد. اللوحة بتعدّل الجاليري والحلاقين والحجز والمواعيد والبيانات من الموبايل.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الموقع اللي العملاء بيشوفوه |
| `admin.html` | لوحة التحكم، وبتدخلها من علامة القفل 🔒 اللي تحت في آخر الموقع |
| `data.json` | كل بيانات الموقع، واللوحة بتعدّله لوحدها |
| `img/` | صورة اليافطة |
| `uploads/` | الصور والفيديوهات اللي بترفعها من اللوحة |
| `admin-vault.json` | بيتعمل لوحده أول مرة، وفيه التوكن متشفّر بالباسورد بتاعك |

## الإعداد، مرة واحدة بس (حوالي 10 دقايق)

> الأسهل تعمله من كمبيوتر. لو من الموبايل، افتح GitHub من المتصفح على وضع "Desktop site".

### 1) اعمل الريبو وارفع الملفات
1. ادخل github.com واعمل **New repository**.
2. سمّيه مثلًا `eldob`، وخليه **Public**، لأن GitHub Pages المجاني محتاج الريبو يبقى Public.
3. فك الـ zip، وبعدين **Add file ← Upload files**، واسحب **كل الملفات والفولدرات**، وبعدها **Commit changes**.

### 2) شغّل الموقع
1. في الريبو ادخل **Settings ← Pages**.
2. **Source** اختار **Deploy from a branch**، والـ **Branch** اختار `main` و `/ (root)`، وبعدين **Save**.
3. استنى دقيقة أو اتنين، وهيظهرلك لينك الموقع:
   `https://اليوزر-بتاعك.github.io/eldob/`

### 3) اعمل توكن للوحة التحكم
1. من صورتك فوق ادخل **Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token**.
2. **Token name**: `eldob-admin`
3. **Expiration**: اختار أطول مدة متاحة.
4. **Repository access**: اختار **Only select repositories**، وبعدين `eldob`.
5. **Permissions ← Repository permissions ← Contents** خليها **Read and write**.
6. **Generate token** وانسخه. بيبدأ بـ `github_pat_` وبيظهر مرة واحدة بس.

### 4) اعمل حساب الأدمن
1. افتح `https://اليوزر-بتاعك.github.io/eldob/admin.html`.
2. اختار **يوزر نيم** و**باسورد**، وحط **مفتاح GitHub** (التوكن). ده مرة واحدة بس.
3. دوس **ابدأ**. من هنا ورايح هتدخل **باليوزر نيم والباسورد بس**.

## الاستخدام كل يوم

1. ادخل الموقع، ودوس على علامة 🔒 الصغيرة اللي تحت خالص، واكتب اليوزر نيم والباسورد.
2. عدّل اللي انت عايزه:
   - **📸 الجاليري**: ضيف صور أو فيديوهات، أو دوس على أي صورة عشان تمسحها أو تغيّر مكانها أو تخليها عريضة.
   - **✂️ الحلاقين**: ضيف حلاق بصورته واسمه، وغيّر حالته: **شغال**، أو **أجازة** (بيظهر وعليه علامة)، أو **مخفي**. ولو حد ساب الشغل امسحه.
   - **📅 الحجز والمواعيد**: افتح الحجز في العيد واقفله بعده، وشغّل شريط إعلان فوق الموقع، وعدّل مواعيد الشغل، وفيه زرار "مقفولين مؤقتًا" لأيام الأجازة.
   - **📞 البيانات**: الأرقام واللينكات واللوكيشن ولينك الدفع.
3. دوس **حفظ ونشر**، والتعديل بيظهر في الموقع خلال دقيقة أو اتنين.

## ملاحظات مهمة
- **الصور** بتتصغّر لوحدها قبل ما تترفع، فارفعها عادي من الموبايل.
- **الفيديو** أقصاه 25 ميجا. خلي الفيديوهات قصيرة، من 10 لـ 20 ثانية.
- **التوكن خلص؟** ادخل اللوحة، وبعدين ⚙️ الإعدادات، وحط مفتاح جديد.
- **نسيت الباسورد؟** امسح ملف `admin-vault.json` من الريبو، وافتح `admin.html` واعمل الإعداد من الأول بتوكن جديد.
- **الأمان**: التوكن محفوظ في الريبو **متشفّر** بالباسورد، ومحدش يقدر يستخدمه من غيره. اختار باسورد قوي، 10 حروف أو أكتر ومش متوقع، وما تبعتش التوكن لحد.
- **دومين خاص** زي `eldob.com`: ممكن تربطه بعدين من **Settings ← Pages ← Custom domain**.

## شيت الحجوزات (Google Sheets)

كل حجز من الموقع بيتسجل لوحده في شيت Google، ورسالة الواتساب بتوصل زي ما هي.
الإعداد مرة واحدة بس، من لوحة التحكم ← 📅 الحجز والمواعيد ← **شيت الحجوزات** ← "إزاي أعمل الشيت؟".
الكود اللي بيتحط في Apps Script موجود في `booking-sheet/Code.gs`.
